# Fusion 360 SCARA 骨架建模清单（a 阶段）

> 目标：搭出「动得对」的关节装配，用 `scara_fusion_spec.md` §4 标定角度驱动，核对吸盘压格。
> 原则：先骨架不画外观；几何尺寸全用参数；坐标系与 params.md 一致（棋盘中心 = 原点，棋盘面 z=0）。
> 关键参数速查：L1=195、L2=185、base=(0,+230)、轴面高 110、滑块行程 35、吸嘴口最高离棋盘面 30。

---

## 第 0 步：建文件与基准
- [ ] 新建设计（单位：mm），命名 `元萝卜SCARA数字样机`
- [ ] 打开 Parameters（工具栏 **Modify → Change Parameters**），先录入：
  | 名称 | 值 | 说明 |
  |---|---|---|
  | L1 | 195 mm | 大臂 |
  | L2 | 185 mm | 小臂 |
  | base_y | 230 mm | 轴心投影距棋盘顶边中心 65mm→即棋盘中心 +230 |
  | axis_h | 110 mm | 两旋转轴面到棋盘面的高度 |
  | z_top | 30 mm | 吸嘴最高位底面到棋盘面 |
  | d3_travel | 35 mm | 滑块行程 |
- [ ] 确认坐标系朝上：进线框视图确认 Z 朝上（若相反，改全局向上方向）

## 第 1 步：棋盘参考体（对格用）
- [ ] 在 z=0 平面画草图：以原点为中心画 **330×330** 正方形（棋盘），再画 **255×255** 中心网格
- [ ] 拉伸成薄板（或直接留在草图层作为参考）
- [ ] 用草图把 255 网格的**中心十字线**画出来，方便自检时对齐吸嘴尖

## 第 2 步：基座 base（固定件）
- [ ] **Component → New Component**，命名 `base`
- [ ] 在 base 内画圆：圆心在 **(0, +base_y)= (0,230)**（草图平面投影在棋盘面上，或用上方平面）
- [ ] 拉伸/旋转成圆柱体，顶面高度 = **axis_h = 110**
- [ ] 基座固定（右键 `base` → Ground / 固定）——它是世界里的不动件
- [ ] 自检点：用 Measure 确认圆柱轴心水平位置 = (0,230)

## 第 3 步：大臂 link1（θ1，旋转）
- [ ] **New Component**，命名 `link1`，画矩形体块，长度 L1=195，中心线过轴 (0,230, 110)，**先让 arm 指向 −Y（朝棋盘中心）**
- [ ] **Assemble → Joint**：选 link1 与 base → **Revolute**（旋转副），对齐到 base 顶面中心竖直轴 = 全局 Z
- [ ] **把「当前姿态」设成关节 0°起点**：创建 Joint 后用旋转将 link1 转到指向 −Y，并在此定义零点（Joint 对话框的 0 位置），使 **模型 θ1=0° = 指向棋盘中心**
- [ ] 给该 Revolute 设**运动限位**：右键关节 → Edit Joint → Motion/Enable limits → 最小 **-150°**、最大 **+15°**（此范围已含零点约定，直接照抄）
- [ ] 手动驱动大臂至 ±极限，目测活动范围与真机一致（165° 扇形，偏棋盘左下→右下）

## 第 4 步：小臂 link2（θ2，旋转）
- [ ] **New Component**，命名 `link2`，矩形体块长 L2=185，一端铰接在 link1 远端
- [ ] **Assemble → Joint**：link2 与 link1 远端 → **Revolute**，轴 = 全局 Z（与大臂共面，高仍 110）
- [ ] 把「伸直（与大臂共线、向远端延伸）」姿态设为 θ2=0 起点
- [ ] 限位 **0° ~ 180°**（单向折叠：θ2=0 表示小臂沿大臂方向伸直）
- [ ] 驱动测试：θ2 只能往一个方向折 180°，不能反向——和真机一致即可

## 第 5 步：滑块 slider（d3）与吸嘴 tool
- [ ] **New Component** `slider`：画竖直杆，与 link2 远端用 **Slider**（滑动副），轴 = 全局 Z
- [ ] 行程限位：0 ~ d3_travel（35mm）
- [ ] **New Component** `tool`：竖直细杆+吸嘴端帽，固定在 slider 上；总长度使**吸嘴口最高时离棋盘面 = 30mm**（即 tool 长度 = link2 远端高度 110 − 30 = 80mm 到吸嘴口，另留吸嘴帽高度）
- [ ] 吸嘴口画一个小十字标记点，作为「压格」的参考中心

## 第 6 步：装配级自检（对标 §4 表）
用 Fusion 的 Move / Joint 驱动把 θ1、θ2 设成表中角度，滑块升到顶，检查吸嘴口十字对格：
- [ ] (0,0) → θ1=-50.79 / θ2=105.56
- [ ] (80,0) → -29.18 / 100.34
- [ ] (-80,0) → -67.54 / 100.34
- [ ] (0,80) → -63.28 / 133.59
- [ ] (0,-80) → -34.28 / 70.70
- [ ] (100,100) → -23.75 / 128.94
- [ ] (100,-100) → -7.30 / 49.72
- [ ] (0,-120) → -22.29 / 45.86
- [ ] 右下远角如 (127,-127) **不要求**——它不可达，别拿来判对错

判定标准：吸嘴口十字落在对应格中心 ±2mm 内（视觉粗判即可）；偏差大 → 优先查 L1/L2 或「θ1=0 指向」偏移。

### 7.1 P1 真机照片对标记录（2026-09-14）

素材：`pics/planform1-5.jpg` 五姿态俯视照（手机斜拍），覆盖：臂伸棋盘左上外 / 左上格域 / V 形折叠（中部）/ 小臂垂直下折（中部）/ 左下越界极限。

方法：以棋盘印刷点阵（±4 线交点，偏移 ±72.86mm）为控制点做单应标定（OpenCV + 最小二乘，残差 P1/P2/P4 = 2.1/2.8/1.7mm）；关节圆头用 HoughCircles 检测、部分区域裁剪精读。

结论：
- [x] **定性对标通过**：五姿态的 θ1 活动域、θ2 单向折叠方向、末端落位区域均与标定表/数字样机约定一致；左下远角姿态（planform5）印证 θ1 ≈ −150° 极限与可达边界行为。
- [x] 单应标定自洽（残差 ≤2.8mm），证明棋盘系照片标定流程可用（b 阶段可复用）。
- [ ] **定量对标受限（记录在案）**：腕/肘圆头反算与 L1/L2 约束偏差 25%~70mm（> 半格 9mm），来源：① 斜拍透视畸变；② 圆头为罩壳外形，中心≠关节轴心；③ 拍摄时基座-棋盘相对摆放漂移（"肩=(0,+230)" 先验失效）。手机斜拍不支持毫米级验证，属设备精度边界而非模型错误。

> **a 阶段验收口径**：以 §8.1 装配体 15 点 MCP 驱动自检（最大 0.259mm）为准；照片对标作定性佐证。
> 若需照片级定量复验：三脚架正上方正交俯拍 + 基座位置现场复测后重做本节（非阻塞项）。

## 第 7 步：收尾与备注
- [ ] 保存为 `.f3d`；可另存一份导出参考几何（如棋盘+格）以便后续装末端/附件时对齐
- [x] 真机对标（P1）：已拍 5 张静止姿态俯视照（`pics/planform1-5.jpg`），**落格级定性通过**（详见 §7.1）
- [ ] **联动价值（务必用 Joint 装配）**：本骨架用 Fusion 的 Joint（旋转副/滑动副）搭建，不只是运动学需要——它同时满足 Autodesk **Synthesis 导出器**（Fusion Exporter）的前提：该插件只接受 Revolute/Slider/Ball 三类关节，会读 Joint 特征导出 Mirabuf，供 b 阶段接触仿真使用。按本清单搭 = 顺手留好了 b 阶段的导出路径。

## 第 8 步：拆成 6 个零件文件 + 外部参照装配体（脚本）

上面第 0~7 步的 GUI 手工建模已被 `fusion/scara_addin/scara_script.py` 全自动化，仅作原理留档。
需要多文件装配体（毕设交付、BOM、零件图）时：

**⚠ 必须睿君在 Fusion 里手动运行脚本**（实用工具 → 脚本和附加模块 → 选 `fusion/scara_addin` → 运行）。
API 规定「保存不能在事务里执行」，走 MCP 一保存就崩插件；手动运行不在事务里，`saveAs` 正常。

- [ ] 把脚本顶部 `TASK` 改成 `"parts"` → 运行 → 云端项目下生成 `SCARA/` 文件夹，内含 6 个零件文件
      （`SCARA-base` / `SCARA-link1` / `SCARA-link2` / `SCARA-sleeve` / `SCARA-shaft` / `SCARA-nozzle`）
- [ ] 关掉这 6 个零件文档的标签页
- [ ] 把 `TASK` 改成 `"assy"` → 运行 → 生成 `SCARA/SCARA-assembly`
- [ ] 核对装配体：6 个引用件、3 个关节（health 全 0）、2 个刚性组、1 个接触集

> `TASK="single"` 是单文件回归模式（一个设计里建全部组件），用于快速迭代与 15 格点运动学自检。
> 三种模式共用一个脚本文件——Fusion 的脚本运行器对同目录 `import` 支持不保证，单文件最稳。
> 拆分口径与装配关系见 `scara_fusion_spec.md` §5。
