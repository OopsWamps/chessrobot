# 扶正附件设计方案（工作底稿）

> 毕设核心章节底稿：面向棋类机器人杂排布的「末端工具 + 被动扶正附件」协同自主取子机构。
> 目标：把厂商「请您整理棋子」的求助降到零。
> 坐标系沿用 params.md：棋盘中心 O(0,0)、Z 向上、棋盘面 z=0；吸嘴口 z 范围 +30 ~ −5（d3 行程 35）。
> 状态：**v0 骨架（2026-09-15）**——几何初推 + 尺寸链自洽性分析；数值待 MATLAB 核算（§4）与真机实测（§8）双重校验。

---

## 1. 问题定义

- 真机（元萝卜四合一启蒙版）遇乱态棋子的原厂绕法：**请用户整理 + 视觉换一颗抓**——求助不为零，是产品明确的能力缺口。
- 硬约束：SCARA 仅竖直末端自由度（无腕部俯仰），**真斜躺/侧立的棋子靠竖直吸盘够不着**（吸盘只能吸朝上的面）。
- 课题：不增加自由度，用**被动附件（固定锥面导槽）+ 原有水平扫动**，把倒伏棋子「扫入→立正→取走」。

## 2. 扶正机理（五步动作）

```
罩 → 压 → 兜 → 吸 → 提
```

| 步 | 动作 | 自由度 | 几何条件 |
|---|---|---|---|
| 罩 | 喇叭口对准侧立子下压，口沿围住子 | d3 下压 | 口沿内径 ≥ 子侧立投影宽 |
| 压 | **继续下压：锥面+口沿把立着的子往腔内挤倒**（推倒主力）；水平微扫只作辅助对中（θ1/θ2 ≤ 1~2mm） | d3（+θ 微调） | 口沿贴盘面（z≈0~2），子无处可倒只能进腔 |
| 兜 | 平躺的子（Ø19×4.5）卡在锥腔最窄下口处，自定心 | 被动 | 下口内径 ≈ 子直径（兜底） |
| 吸 | 腔顶中心吸嘴下压吸住平躺子顶面 | d3 | 吸嘴口行程可达子顶面 |
| 提 | 整腔提起，子随吸盘走（喇叭口不抓子） | d3 上提 | 子与口沿间隙不过大 |

**为什么是喇叭口（下小上大）而不是直筒**：下口最窄 = 兜底防子再滚出；上腔张开 = 立着的子容易进、倒下时锥面引导。

> ⚠ 机理修正（2026-09-15 MATLAB 核算，§4）：原设想「水平扫动 5~10mm 推倒立子」在密排格位**不可行**——
> 推倒需偏移 ≥2.25mm（越过子中心线），而密排口沿扫动上限只有 1.25mm。故推倒主力改为**下压挤倒**（压入即倒），
> 扫动仅用于棋盒/散乱区（无邻子约束）的大偏移辅助。

## 3. 几何初推（v0 参数）

### 3.1 口径上限推导（围棋/五子棋场景）

- 围棋格距：现按 255/12 = **21.25mm 假设**（P0 待实测）
- 棋子 Ø19 → 密排相邻净空 21.25 − 19 = **2.25mm**
- 附件外径上限：**D_out ≤ 21mm**（比格距小，保证密排格位也能下探；仅余 0.25 名义间隙 → 实际是否可入密排格另验，不强求）

### 3.2 v0 参数表

| 参数 | 值 | 推导 |
|---|---|---|
| 下口外径 D_out | 21.0 mm | ≤21 上限顶格用满（核算后定，见 §4.2） |
| 下口内径 D_in | 20.0 mm | ≈ 子 Ø19 + 1 走子间隙，兜底自定心 |
| 壁厚 t | 0.5 mm | 3D 打印薄壁极限（21/20 → t=0.5） |
| 裙筒全长 | 27 mm | 口沿→上端；上段收窄 Ø17.4 内孔 ×≥6 过盈套接吸嘴 |
| 内锥半角 α | ≈ 2.7° | 单边张口 (20−17.4)/2=1.3，锥长 27 → tanα≈0.048 |
| 口沿伸出量 h | **−2 mm（口沿低于吸嘴口 2mm）** | 见 §4 尺寸链 |
| 材质 | 硬质（PLA/PETG）+ 口沿可选软胶圈 | 口沿是唯一与盘面摩擦件 → 可换 |

> v1 预留：锥腔上段（立子活动区，0~19 高）改 **Ø19 直筒 + 三筋悬支吸嘴**，立子↔吸嘴间隙 0.585 → ~1.0mm（§4.3）。

### 3.3 口沿低于吸嘴口 h=−2 的理由（尺寸链核心）

吸取位形（吸平躺子，子顶 z=4.5）：
- 吸嘴口 z = 4.5（贴合子顶，密封吸附）
- 口沿 z = 4.5 − 2 = **2.5 > 0** → 口沿悬空不碰盘面 ✓

扫动位形（口沿贴盘做导槽）：
- 口沿 z = 0~2 → 吸嘴口 z = 2~4 → 吸嘴悬空不碰盘 ✓
- 口沿（硬质、可换）承担与盘面/邻子的全部摩擦 ✓

对拍原机：吸嘴口压到底 z=−5 本来就是「过压吸薄子」的软胶过压行程；本方案把摩擦转移给可换口沿，不增加新自由度。

## 4. 尺寸链核算（✅ MATLAB 已验，`matlab/scara_corrector_envelope.m`，2026-09-15）

### 4.1 位形 d3 表（行程 0~35 内全 PASS）

| 位形 | 口沿 z | 吸嘴口 z | d3 | 检查 |
|---|---|---|---|---|
| 待机/移位 | 28 | 30 | 0 | ✓ |
| 压入（扶正） | 1 | 3 | 27 | ✓ |
| 吸合 | 2.5 | 4.5 | 25.5 | ✓ |
| 提起 | 随 d3 回升 | — | 回 0 | 子兜在腔内随行 ✓ |

### 4.2 干涉与净空核算结果

| 项 | 数值 | 判定 |
|---|---|---|
| 密排静止下探：口沿外缘↔邻子间隙 | **1.25mm** (= 21.25 − 10.5 − 9.5) | PASS（>0.3 要求）|
| 密排扫动上限 s_max | **1.25mm** | < 推倒所需 2.25mm → **密排不可扫** |
| 推倒立子所需偏移 | ≥2.25mm（口沿内缘越过子中心线） | → 改由下压挤倒承担 |
| 裙筒净高 27 vs 立子高 19+2 余量 | PASS | |
| 立子顶处内腔半径 | 9.085mm | 立子↔吸嘴间隙仅 **0.585mm**，偏紧 ⚠ |

### 4.3 核算引出的 v1 改进项

1. **立子↔吸嘴间隙偏紧**（0.585mm）：v1 将锥腔上段改为 **Ø19 直筒段**（占立子活动区全长），吸嘴改三筋悬支定心 → 间隙加大到 ~1.0mm。
2. **密排扶正的新结论**（推翻旧认知「密排塞不进 Ø21」）：静止下探间隙 1.25mm > 0，**密排格位压入扶正理论可行**；但 1.25mm 名义间隙要求视觉定位精度 ≤±1mm（真机标称取放精度 1mm，临界）→ 密排扶正实测定，不强求的设计口径不变。
3. 扫动动作从「必备」降级为「棋盒/散乱区辅助」，包线图见 `matlab/scara_corrector_result.png`。

## 5. 棋种适配（开放决策）

| 棋种 | 子规格 | 倒伏态 | 本附件 |
|---|---|---|---|
| 围棋/五子 | Ø19×4.5 扁椭球 | 侧立（高 19、宽 4.5） | ✅ 口径正好兜底 |
| 象棋/国象 | Ø23.5×8 圆柱 | 侧躺（Ø23.5 横向） | ❌ D_out 21 装不下 Ø23.5 |

**决策点 D1**：单口径（只服务围/五，象/国象保持原厂求助）vs 双口径可换（加 Ø25.5 口径件服务象/国象，象棋格距大、邻子净空足）。
倾向：**先做 Ø20 单口径**（围/五是高频乱态场景：棋盒倒伏主要发生在围棋），象棋圆柱倒伏概率低且侧躺态真空吸盘直接吸侧面可能就够（8mm 高的侧面 23.5×8 面积足够）——待实测验证后再决定是否开第二口径。

## 6. 场景优先级

1. **棋盒内倒伏**（主战场）：盒 214×62×26 ×2、棋子随取出而降低的动态料面；盒内空间半开放，喇叭口动作包线最宽松
2. **散乱区**：盘面/盘外散子，孤立子居多 → 罩-扫一次到位
3. **密排满盘**：不强求（净空 2.25mm），仍走原机「视觉换一颗抓」

## 7. 接口与制造

- 套接方式 v0：过盈套接（上段 Ø17.4 内孔 × ≥6 长套吸嘴下部），打印方向 Z 向、壁厚均匀
- 候选升级：卡扣 + 轴向限位（防扫动时附件旋转/脱落）——待 v1
- 口沿倒角 R0.3（防刮盘面）
