# 机械手参数表

研究对象：元萝卜 AI 下棋机器人「四合一启蒙版」

## 1. 构型

三轴三自由度 **SCARA 型**机械手：

| 关节 | 类型 | 变量 | 说明 |
|---|---|---|---|
| 1 | 旋转 | θ1 | 基座水平旋转 |
| 2 | 旋转 | θ2 | 肘部水平旋转 |
| 3 | 移动 | d3 | 竖直升降（吸盘上下） |
| 末端 | — | — | 真空吸盘（吸泵） |

## 2. 坐标系约定

- 世界坐标系原点在**棋盘中心** O(0,0)，Z 轴竖直向上，棋盘平面为 XY
- 棋盘 **330 × 330 mm 正方形**，范围 x,y ∈ [-165, 165] mm
- 基座（关节 1 旋转轴）投影在**棋盘上边缘中点外侧 (0, +230) mm**（2026-09-08 实测：轴心在棋盘顶边中心上方外约 65 mm，即 165+65）；基座高（轴面 → 棋盘面）H = 110 mm
- 关节 1、2 绕 Z 轴旋转（水平面内旋转），关节 3 沿 Z 轴平移（**向下为正**）

### 3.2 待实测 / 待核实

竖直链推导（运动学用）：
- 两旋转轴面在 z = +110（棋盘面 z=0，Z 向上）；
- 吸盘口可达 Z 范围 = z_top − d3 … z_top = **−5 ~ +30 mm**（相对棋盘面）。

> 注：θ1/θ2 范围实际已确认，不再归入「假设值」。

### 3.3 运动学（含基座偏移）

正运动学（基座在 (0, +230)，轴心投影，θ1=0 指正下）：

```
x = L1·cosθ1 + L2·cos(θ1+θ2)
y = 230 + L1·sinθ1 + L2·sin(θ1+θ2)
z = d3
```

逆运动学：先将目标点平移到基座坐标系 `x' = x`、`y' = y - 230`，再按标准 SCARA 反解。

可达性注意（base_y=230、L=[195,185] 复核）：255 网格内除**最右下角 (约 x≥+120 且 y≤-120)** 因 θ1 上限 +15° 与臂展极限而不可达外，其余全可达——右下远端是天然可达边界，设计末端/附件时注意。
