> 用途：在 Fusion 360 里搭「动得对」的元萝卜 SCARA 数字样机，并用棋盘可达格点做第一层自检。
> 原则：**先动得对（运动学），不追求外观**；带 ⚠ 的为待实测占位，量完回填。

## 3. Fusion 装配建步骤（骨架版）
1. 建组件 `base`（基座圆柱，顶面高 = axis_h = 110）→ 轴心在 (0, base_y)=(0, 230)，**并固定**。
2. 建组件 `link1`：转台轮毂 + 大臂(长 L1) + 肘部轮毂，画在 **z=110** 平面、拉伸 20mm。
3. 建组件 `link2`：肘部轮毂 + 小臂(长 L2) + 腕部轮毂，画在 **z=130** 平面、拉伸 20mm。
4. 建末端（实测 2026-09-11）：**工具挂点 z=95**（≈气泵顶，在臂腕面之下 ~35），支架从腕面接到挂点。
   **第一段** Ø37×**38** 套筒固定在挂点下方（掏 Ø30.6 内孔作导向）；**第二段** Ø30 轴长 **40mm**
   （= 挂点 95 − z_top 30 − 吸嘴 25），在孔里滑动；**吸嘴** Ø17×25 随第二段平移。
   行程 0 时吸嘴口 z=**30**（= 实测 z_top）、轴露出套筒底 **2mm**；压到底（−35）时吸嘴口 z=**−5**（= 实测最低）、轴**露出 37mm**。
   > ⚠ 套筒缩到 38 后，「收缩态 z_top=30」「全伸只露出 25」「挂点 95」三者只能取二（2026-09-11 已确认）：
   > 本模型保 **z_top=30**（吸得到棋子优先），代价是全伸露出 37mm——轴在孔内仍留 3mm 导向。
5. 放棋盘平面一个参考体（330×330）用于对格。

> 驱动时只改 θ1、θ2、d3 三个运动输入，其余全固定。先不做外形，臂杆用矩形体块即可。

### 3.1 ✅ 已验证的建模配方（2026-09-10，脚本 `fusion/scara_addin/scara_script.py`）
> 数值验收：15 个标定格点吸嘴口误差 **≤0.26mm**；d3 行程 0 → 吸嘴 z=30mm，−35mm → z=−5mm；三关节 health 全 0。
> **直接跑脚本即可**（Fusion → 实用工具 → 脚本和附加模块 → 选 `fusion/scara_addin` → 运行；请在空设计里跑）。

三条**必须遵守**的关节建法（否则 Fusion 报"距离冲突/部件关系冲突"，关节永久转不动）：
1. **被参考的零件必须是独立组件并固定**（`Occurrence.isGrounded=True`）。实体直接建在根组件里 → 关节第二端 `occurrenceTwo=None` → 冲突。
2. **关节几何用"面"，不能用两个重合的草图点**（点-点关节旋转轴退化）。
3. 统一配对「活动件轮毂**底面** ↔ 参考件圆/顶面」＋ **`JointInput.isFlipped = True`**：
   - th1: link1 转台轮毂底面 ↔ base 顶面
   - th2: link2 肘部轮毂底面 ↔ link1 肘部轮毂顶面
   - d3 : 第二段轴顶面 ↔ 第一段套筒的顶环面（滑动副，`isFlipped = False`）
   此时 θ1=0 即指向 −Y、θ2=0 即大小臂伸直，不用再手工找零点。

其它坑：`isFlipped` 只能设在 `JointInput` 上；驱动后**不要** `design.computeAll()`（会重置回 0）；
滑动副正方向是 **+Z（向上）**，所以下压用**负值**（限位 −d3_travel ~ 0）。

**⚠ 贴合面法线朝向决定会不会"装反"**（2026-09-11 踩过两次）：
- 两面法线**反向**（活动件的底面 ↔ 参考件的顶面）→ `isFlipped = True` 正确；
- 两面法线**同向**（活动件的顶面 ↔ 参考件的顶环面）→ 若仍设 `isFlipped = True`，Fusion 会把整个活动件
  **翻转 180°**装到参考件上方（实测吸嘴口从 z=30 跑到 z=230）；此时必须 `isFlipped = False`。

判据很简单：**装完读一下末端关键点坐标，不对就把 `isFlipped` 取反**（一次就能改对）。

**层高约定**（外形参数，不影响运动学）：link1 层 z=110、link2 层 z=130、腕上表面 z=150、吸嘴口 z=30（最高位）。

## 5. 多文件装配体（脚本 `scara_script.py`，2026-09-11）

同一份脚本靠顶部 `TASK` 常量切换三个模式：

| `TASK` | 产出 | 用途 |
|---|---|---|
| `"single"` | 一个设计里建 base/link1/link2/slider 四组件 + 三关节 | 快速迭代、§4 的 15 格点自检（回归基线）|
| `"parts"` | 云端 `SCARA/` 下 6 个零件文件 | 真·单件，出零件图/BOM |
| `"assy"` | 云端 `SCARA/SCARA-assembly` | 外部参照装配体，可驱动 |
| `"scene"` | 当前设计里建棋盘(330×330×12 占位)+网格刻线(255/12 格)+13 路围棋子×169（幂等） | 扶正附件 / b 阶段仿真的几何环境（2026-09-15 加）|

**⚠ 必须睿君在 Fusion 里手动运行**：API 规定「保存不能在事务里执行」（`Document.saveAs` 文档原文），
MCP 每次执行都开事务 → 保存必崩插件；手动运行不在事务里，正常。

### 5.1 零件拆分（6 个）
| 文件 | 内容 | 单文件模式里的归属 |
|---|---|---|
| `SCARA-base` | 底盘+球体+环带+肩部（旋转体） | `base` 组件 |
| `SCARA-link1` | 大臂（肩部 housing+转台+臂板+肘端+销，一个整体） | `link1` 组件 |
| `SCARA-link2` | 小臂（肘端轴承台+臂板+腕端圆头） | `link2` 实体 1 |
| `SCARA-sleeve` | 套筒 Ø37×38（含 Ø30.6 内孔） | `link2` 实体 2 |
| `SCARA-shaft` | 伸缩轴 Ø30×40 | `slider` 实体 1 |
| `SCARA-nozzle` | 吸嘴 Ø17×25 | `slider` 实体 2 |

### 5.2 装配关系
| 关系 | 类型 | 说明 |
|---|---|---|
| link1 ↔ base | 旋转 `joint_th1` | θ1，限位 −150°~+15° |
| link2 ↔ link1 | 旋转 `joint_th2` | θ2，Fusion 侧限位 0~−180°（负值=折叠，旋向与标定表相反）|
| shaft ↔ sleeve | 滑动 `joint_d3` | 下压 −35~0 mm |
| sleeve ↔ link2 | **刚性组** `rigid_sleeve_link2` | 套筒紧固在小臂上 |
| nozzle ↔ shaft | **刚性组** `rigid_nozzle_shaft` | 吸嘴随伸缩轴平移 |

### 5.3 三条实现约定
1. **零件按装配位置绝对坐标建模** → 装配体里用单位矩阵插入即原样落位（伸缩轴/吸嘴建在挂点下方，
   靠 `joint_d3` 顶到套筒顶环面后自动就位，靠刚性组把吸嘴带过去）。
2. **文件名/组件名一律 ASCII** —— 中文名经 GBK 临时文件通道会损坏。
3. **倒角与上色在零件文件里做**：外部参照的零件在装配体里是只读的，装配体改不动它们。
   关节面一律取自 `occurrence.bRepBodies`（装配上下文），单文件与装配模式共用一条代码路径。
